# 번역 지침

- 외부 기계 번역을 쓰지 않고 직접 번역했습니다.
- 전국시대 사극 말투로 씁니다. 주군에게는 하십시오체·하오체, 아랫사람에게는 하게체·해라체. 원문의 정중함·거만함·노인·여성 말투 차이를 살립니다.
- 일본 인명·지명은 국립국어원 일본어 표기법을 따릅니다(어두 거센소리 없음, 장음 생략: 다케다, 도쿠가와, 오다, 교토, 오사카).
- 직함·용어: 다이묘, 가로, 아시가루, 슈고, 간레이, 정이대장군, 조정, 천하, 잇키, 가보, 병량, 평정, 모반, 내응 등.
- 메시지의 제어 코드는 그대로 둡니다. 단어 호출(`01 43 xx xx`)과 변수(`02 0x xx`)는 한국어 어순에 맞춰 같은 문장 안에서 옮길 수 있고, 일본어 활용 어미를 내는 호출은 지우고 뜻을 직접 씁니다.
- 변수(이름·지명) 뒤 조사는 `이(가)`, `은(는)`, `을(를)`, `와(과)`, `(으)로` 로 씁니다. 실행 중에 받침에 맞춰 하나로 바뀝니다.
- 줄 폭은 창 폭(`maxw`, 공백 0.5·그 밖 1)을 넘지 않게 직접 줄바꿈합니다. 시나리오 설명 창은 폭 17입니다.
- 한국어 결과에 가나·한자가 남으면 안 됩니다.
